
## Milestone 1: Initialize MXB V3.0 Engineering Roadmap
Started strategic architectural and feature roadmap for MXB V3.0 development lifecycle.

## Milestone 2: Plan local vision multimodal input integration
Design architecture for integrating local Vision-LLMs (e.g. LLaVA, MiniCPM) for visual desktop analysis.

## Milestone 3: Add screen OCR and visual grounding targets
Plan real-time screen parsing via Windows Media OCR APIs and coordinate mapping for UI automation.

## Milestone 4: Outline multi-agent tool calling architecture
Map out autonomous sub-agent orchestration for delegating complex multi-step OS workflows.

## Milestone 5: Add native Windows Bluetooth audio profile handling
Design automatic switching between Handsfree profile and Stereo audio for wireless headsets.

## Milestone 6: Plan DirectML hardware acceleration for Whisper
Target DirectML execution provider for low-latency Whisper STT inference on AMD/Intel/NVIDIA GPUs.

## Milestone 7: Add SQLite vector database for long-term semantic embeddings
Replace in-memory TF-IDF with persistent SQLite sqlite-vec vector store with local nomic embeddings.

## Milestone 8: Outline automated daily calendar briefing features
Plan local Outlook and Google Calendar synchronization for morning voice agenda readouts.

## Milestone 9: Plan custom wake-word training pipeline with openWakeWord
Document pipeline for training user-personalized wake words using synthetic voice augmentations.
